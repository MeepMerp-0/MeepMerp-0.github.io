[Portfolio](https://meepmerp-0.github.io/) · [GitHub](https://github.com/MeepMerp-0) · [Email](mailto:jason.selerio@gmail.com)

My portfolio, built with React, Vite and Three.js. Aki is the chat assistant on the site. It runs on a Cloudflare Worker.

```bash
npm ci
npm run dev   # local dev server
npm test      # site and Worker tests
```

The page content is in `src/data/`, and the Worker is in `worker/`. A push to `main` deploys the site to GitHub Pages and deploys the Worker.
