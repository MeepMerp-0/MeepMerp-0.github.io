# ICM agent entry

This file applies to work inside `icm/`. Read [CONTEXT.md](CONTEXT.md) to route a request, then read only the selected stage contract and its listed inputs. For implementation in sibling `src/`, `worker/`, or release files, the repository root must explicitly instruct the agent to read this file; an `icm/AGENTS.md` does not automatically govern sibling paths.

Use the [development model routing policy](shared/model-routing.md) for role authority, reasoning effort, security, verification, and release boundaries. The [run contract](shared/run-contract.md) defines evidence and status. Do not infer completion from a file's existence or claim a check that was not run.

For the portfolio rework, the [current design contract](shared/design-preferences.md) controls page/project order, a lightweight actual Three.js Hero, true Three.js Work scenes and native scroll pinning, themes/responsiveness, and Aki's boundary: preserve the original robot and functional/backend behavior; permit scoped chat presentation only. It supersedes older example permissions, blanket Aki freezes, and general role descriptions that would otherwise expand this task. No new canned Aki walkthrough is authorized.

Follow the [branch workflow](shared/run-contract.md#branch-workflow): future application work starts on a new feature branch from the exact latest fetched documentation base. Explicitly authorized documentation-only maintenance may update that base directly; it does not authorize application changes or deployment.

This workspace is Markdown guidance and reviewable artifacts. It does not execute stages, install tools, modify the portfolio, or authorize merge or deployment by itself. Stay within the task's granted scope and existing repository instructions.

For demo requests, load [demo boundary](shared/demo-boundary.md) and [demo catalog](shared/demo-catalog.md) before handling source material. Apply their public/private evidence separation to every stage and release file. The [demo release checklist](references/demo-release-checklist.md) is a required review gate. Do not copy private source, assets, records, scans, or provenance into this public workspace; access to inspect does not authorize disclosure.
